# 阅读这些入口需要的 C 符号

在 `src/model/qwen3.c` 中，会遇到：

```c
const QwenConfig *config = &model->config;
```

可以将它读作：“找到这份模型的配置，将它的地址记为 `config`，通过这个名字读取配置。”

| 写法                    | 含义                                                   |
| ----------------------- | ------------------------------------------------------ |
| `QwenConfig`          | 结构体类型，一组相关字段的定义                         |
| `model->config`       | `model` 是指针，通过它访问所指模型的 `config` 字段 |
| `&model->config`      | 取得这个字段的地址                                     |
| `QwenConfig *config`  | 声明一个保存配置地址的变量                             |
| `const`               | 通过这个指针读取配置                                   |
| `config->hidden_size` | 读取配置里的向量长度，当前模型为 1024                  |

`model->config` 与 `(*model).config` 含义相同：`*model` 找到指针所指的结构体，
后面的 `.config` 访问其中一个成员。

## 指针与数组

```c
float *hidden;
```

这行声明保存一个地址。程序在 `src/runtime/memory.c` 中分配连续空间，再将地址保存到
`runtime->hidden`。当前模型需要 1024 个 `float`，每个 `float` 占 4 个字节。

`hidden[0]` 表示第一个元素，`hidden[1]` 表示第二个元素。
`hidden + 128` 指向第 129 个浮点数；移动的单位由 `float` 这个类型决定。

因此，下面这一段是在选取当前注意力头的起始位置：

```c
runtime->query + head * config->head_dim
```

`head_dim` 为 128。当 `head` 为 0 时访问第一个头，当 `head` 为 1 时向后移动 128 个元素。

## 函数参数怎样传递结果

```c
rmsnorm_forward(&model->norm, runtime->hidden, runtime->normalized);
```

三个参数分别是：这个 RMSNorm 组件的地址、输入数组的地址、输出数组的地址。
函数读取 `hidden`，将结果写入 `normalized`。在代码中，输出数组的位置由调用者明确指定。

| 返回值                           | 在当前代码中的含义                       |
| -------------------------------- | ---------------------------------------- |
| 层函数返回 `1`                 | 本次计算完成                             |
| 层函数返回 `0`                 | 本次计算失败，调用者立即停止             |
| `qwen_forward()` 返回浮点指针  | 指向词表分数数组 `logits`              |
| `qwen_forward()` 返回 `NULL` | 计算失败                                 |
| `tokenizer_encode()` 返回整数  | 输出了多少个 token 编号，`-1` 表示失败 |

## 合并后为什么要移动数组

`Hello` 最初对应编号数组 `[39, 68, 75, 75, 78]`。
词表规则将第二、第三个条目合并为 `301` 后，数组需要变成 `[39, 301, 75, 78]`。

`bpe.c` 中的 `memmove()` 将后面的编号向前移动，`--count` 将有效元素数量减一。
分配的数组空间仍然存在，有效内容由 `count` 指定。

`size_t` 常用于字节数、数组长度等容量；`uint8_t` 表示一个 8 位无符号整数，
这里用来保存字节；`uint32_t` 表示 32 位无符号整数，这份模型用它存储词表编号和文件位置。
